# Talkito Android pilot downloads

This public repository distributes signed Talkito Android APKs. Application
source, signing keys and service credentials are maintained separately.

## Version 1.0.1

[Download the signed pilot APK](https://talkito.ir/android/download).

[Immutable GitHub fallback](https://raw.githubusercontent.com/masoudSeraj/talkito-android-releases/b902b370b002b76d1eed88b1e3547bcf77dd7f48/talkito-1.0.1.apk).

- Android 7.0 or later; ARM 32-bit and 64-bit; version code 2.
- File size: 35,058,740 bytes. Verify the SHA-256 against [SHA256SUMS](SHA256SUMS).
- Login and chat services are active. Physical-device acceptance remains pending;
  this release is a customer pilot.
- Use an existing Talkito account and its phone OTP. Free plans retain viewing,
  notifications and browser access; mobile sending requires an eligible paid plan
  and existing main message credits.
  Notifications depend on device permissions, network and battery settings.
- Three UI fixes are deferred: navigating during pending sends, retrying a failed
  notification open and displaying many attachments in the composer.

Public product and setup guide: [talkito.ir/android](https://talkito.ir/android).
