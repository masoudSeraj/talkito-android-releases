# Talkito Android pilot downloads

This public repository distributes signed Talkito Android APKs. Application
source, signing keys and service credentials are maintained separately.

## Version 1.0.1

[Download the signed pilot APK](https://raw.githubusercontent.com/masoudSeraj/talkito-android-releases/main/talkito-1.0.1.apk).

- Android 7.0 or later; ARM 32-bit and 64-bit; version code 2.
- File size: 35,058,740 bytes. Verify the SHA-256 against [SHA256SUMS](SHA256SUMS).
- Pilot status: login and chat backend deployment and physical-device acceptance
  are still pending. Download availability does not establish service readiness.
- After service activation, use an existing Talkito account and its phone OTP.
  Notifications depend on device permissions, network and battery settings.

Public product and setup guide: [talkito.ir/android](https://talkito.ir/android).
